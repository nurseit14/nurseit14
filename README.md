### Featured projects

| Project | What it does |
|---|---|
| **[Crop-Yield-Prediction](https://github.com/nurseit14/Crop-Yield-Prediction)** | Benchmarks 5 ML models on FAO data — Random Forest hits test R² ≈ 0.99, but crop-stratified GroupKFold turns that negative for every model. The interesting part isn't the leaderboard, it's why. |
| **[Knowledge-graph-pipeline](https://github.com/nurseit14/Knowledge-graph-pipeline)** | LLM-based extraction of entity–relation triplets from financial news, loaded into Neo4j, queryable in plain English via a natural-language-to-Cypher interface. |
| **[ai-ecommerce-assistant](https://github.com/nurseit14/ai-ecommerce-assistant)** | Hybrid product search for a 15k+ item technical catalog: semantic search + FAISS + fuzzy/attribute matching, two-stage reranking, and an OpenAI tool-calling agent on top. |
| **[Multi-Agent-Investment-Analysis-System](https://github.com/nurseit14)** | Multi-agent financial analysis pipeline (CrewAI + LangChain) with retrieval-augmented generation. |
| **[Fraud-detector-main](https://github.com/nurseit14/Fraud-detector-main)** | Fraud classifier on 284,807 transactions (F1 0.908, ROC-AUC 0.995), served through a FastAPI backend with a dashboard. |
